## 事前準備（講師）

### 1. テンプレートリポジトリを用意する

参加者が **「Use this template」** を使えるようにします。

1. 配布用リポジトリを用意し、次を配置:
   - `scripts/`（`tts_gemini.py`, `render_infographic.py`, `pubmed_fetch.py`, `requirements.txt`）
   - `prompts/weekly_radio_prompt.md` ← **`template/weekly_radio_prompt.md` の内容**を置く
     （小児腎臓病に固定された版ではなく、設定欄付きの汎用版）
   - `handson/`（この資料一式）
   - `reports/` は空でよい（サンプルを1つ残すと完成形が伝わりやすい）
2. リポジトリを **Public** にする
3. **Settings → General → 「Template repository」にチェック** ← これを忘れると
   参加者に「Use this template」ボタンが出ません
4. リポジトリ URL を参加者に共有

### 2. 参加者への事前アナウンス

**当日アカウントを作らせると30分では終わりません。** 数日前に告知してください。

> 次の4つを当日までに作成し、ログインできる状態でお越しください。
> ① GitHub アカウント ② Notion アカウント ③ Google アカウント
> ④ Claude の Pro または Max プラン
> また、手元の Claude Code で `/login` を済ませておいてください。

### 3. 自分で一度通しで実施する

初回は環境のセットアップスクリプトのキャッシュ構築が走るため、
2回目以降より時間がかかります。**必ず事前に1周してください。**

## 30分の配分と、意図的に切り捨てたもの

| 時間 | ステップ | 講師の注意 |
|---|---|---|
| 0:00–0:03 | 全体像 | 完成物（Notion ページと音声）を**実際に見せる**のが最も効く |
| 0:03–0:07 | リポジトリ作成 | Public 選択を全員に確認させる |
| 0:07–0:11 | GitHub 連携 | `/web-setup` の方が圧倒的に速い。App 導入は希望者のみ |
| 0:11–0:15 | コネクタ | Notion の OAuth でページ選択を忘れる人が多い |
| 0:15–0:19 | Gemini キー | 画面共有しないよう注意喚起する |
| 0:19–0:25 | Routine 設定 | **branch push 権限**と**環境変数**を全員に復唱確認 |
| 0:25–0:30 | Run now | 完走は待たない。「メールが届きます」で解散 |

**切り捨てたもの**（30分に収めるための判断）:

- 各自の Notion データベースの手作りは行わない → **初回実行時に Claude が自動作成**する設計にした
- スクリプトの中身の解説は行わない → テンプレをそのまま使う
- テーマの差し替えは**持ち帰り課題**（GUIDE.md 末尾）にした

## 想定される質問と回答

**Q. なぜ Public リポジトリにする必要があるのか**
A. Notion に音声を埋め込む際、GitHub の raw URL からファイルを取り込むためです。
Private だと Notion 側から取得できません。業務データを扱う場合は、
Notion に直接アップロードする方式に作り替える必要があります。

**Q. 鍵をコネクタではなく環境変数で持つのはなぜか**
A. 外部サービスへの接続方法が2系統あるためです。PubMed と Notion は Claude のコネクタ
（通信は Anthropic 側）、Gemini はサンドボックスから直接呼ぶので環境変数で渡します。
ネットワーク許可リストの変更が不要なのは、`*.googleapis.com` が既定で許可されているからです。

**Q. Routine のプロンプトを直接書かず、リポジトリの手順書を読ませるのはなぜか**
A. 内容の変更が Git の履歴に残り、Routine 画面を開き直さずに済むためです。
参加者が自分のテーマに変えるときも、ファイルを1つ編集して push するだけになります。

**Q. 費用はかかるか**
A. Gemini は無料枠内。Claude は Pro / Max の通常利用枠を消費し、Routine には
1日あたりの実行回数上限があります。GitHub と Notion は無料プランで足ります。

## 講師が把握しておくべき仕様（つまずきの原因になりやすい順）

1. **Routine の push 先制限** — 既定では `claude/` 接頭辞のブランチのみ。`main` に push するには
   Permissions の **Allow unrestricted branch pushes** が必須。
2. **環境変数は `.env` 形式で引用符なし** — `KEY="value"` と書くと引用符も値に含まれる。
3. **実行一覧の緑色は成功を意味しない** — セッションが異常終了しなかっただけ。中身の確認が必要。
4. **ネットワーク遮断は 403 で返る** — 許可外ホストは `x-deny-reason: host_not_allowed`。
   PubMed の API を直接叩こうとすると失敗するが、コネクタ経由なら通る。
5. **環境のキャッシュ** — セットアップスクリプトや許可ドメインを変更すると再構築が走る。
6. **Notion 無料プランのファイル上限** — 5MiB。MP3 はこれを超えないよう生成する設計。
